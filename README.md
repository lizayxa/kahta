# Bolta Khata

Dukandaron ke liye bol kar khata rakhne wala offline software (PWA).
Udhaar, wapsi, naqad sale, stock, kharcha aur din ki report.

Live link: https://lizayxa.github.io/kahta/

## Awaz (mic)
- Internet ho to: Chrome/Edge ka Google mic (Roman ya Urdu).
- Internet na ho to: Vosk offline mic, Hindi model (`models/vosk-model-small-hi-0.22.tar.gz`, Apache 2.0, alphacephei.com).
  Ek dafa Report tab se download hota hai, phir phone ki IndexedDB mein rehta hai.
- `vosk.js` = vosk-browser 0.0.8 (Apache 2.0).
